## Documentation languages

Every Markdown document has separate English (`NAME.md`) and Polish
(`NAME_PL.md`) versions. Put a link to the other language at the start of each.
Links in the body should lead to documents in the same language. Update both
versions when changing content; preserve option names, MQTT topics and literal
log messages. YAML examples remain shared configurations.
