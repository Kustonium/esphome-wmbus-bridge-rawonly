## Wersje językowe dokumentacji

Każdy dokument Markdown ma dwie osobne wersje: angielską `NAZWA.md`
i polską `NAZWA_PL.md`. Na początku obu umieszczaj link do drugiego języka.
Odnośniki w treści powinny prowadzić do dokumentów w tym samym języku.
Zmieniając opis, aktualizuj obie wersje; zachowuj nazwy opcji, tematów MQTT
i dosłowne komunikaty logów. Przykłady YAML pozostają wspólnymi konfiguracjami.
